# Saggart & Citywest Together

A mobile-first educational resource and digital hub designed to foster connection, belonging and cultural understanding across Saggart and Citywest, County Dublin.

## Features

- Home, Learn, Quiz, About, Contact, Privacy and custom 404 pages
- Five source-backed learning sections
- 24 questions, with 10 shuffled without replacement per attempt
- Immediate explanations and primary-source links
- Device-local best score
- Keyboard-operable navigation and quiz with visible focus and live feedback
- Responsive design and reduced-motion support
- No runtime dependencies, trackers or external media
- Automated quiz, data, link and asset tests

## Run locally

```bash
npm run serve
```

Open `http://localhost:4173`.

## Test

```bash
npm test
```

Content was independently compiled from South Dublin County Council, the Placenames Database of Ireland and other official public resources. The prototype is not a formally endorsed Council product. Source review date: **14 August 2026**.

The contact form validates locally and does not transmit messages.
