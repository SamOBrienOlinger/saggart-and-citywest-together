Accessibility

Using this website

We want everyone to be able to explore, understand and use this community website.

Our accessibility target

We aim to follow the Web Content Accessibility Guidelines (WCAG) 2.2, Level AA. These are widely used standards for accessible websites. We use clear headings, readable colours, large buttons and layouts that fit small screens. You can use a keyboard and see which link or button is selected.

What the website supports

  • Keyboard navigation and a skip link
  • Headings, labels and updates that work with screen readers
  • Text resizing and page zoom without loss of content
  • Pages that fit screens as narrow as 320 pixels without sideways scrolling
  • Support for your device’s settings for less movement, stronger contrast and system colours
  • Clear button labels and instructions

Known limits

We test the site with automated checks and a keyboard, but these cannot cover everyone’s needs. We also need hands-on testing and feedback from disabled users. Other websites linked here have their own accessibility features. Translations are automated by Google and may contain errors; the original English content remains the reference version.

Tell us about a problem

If something is difficult to use, email saggartcitywesttogether@gmail.com. Please tell us which page you were using, what went wrong and, if you are comfortable doing so, the browser or assistive technology involved.
