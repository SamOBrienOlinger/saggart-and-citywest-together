Accessibility

Using this website

We want everyone to be able to explore, understand and use this community resource.

Our accessibility target

We aim to meet the Web Content Accessibility Guidelines (WCAG) 2.2 at Level AA and apply Level AAA improvements where practical. This includes keyboard access, visible focus, readable contrast, flexible text, clear headings, large touch targets and layouts that reflow on small screens.

What the website supports

  • Keyboard navigation and a skip link
  • Screen-reader-friendly landmarks, labels and status messages
  • Text resizing and page zoom without loss of content
  • Mobile layouts down to 320 CSS pixels without sideways page scrolling
  • Reduced motion, increased contrast and forced-colour preferences
  • Clear form labels, instructions and validation feedback

Known limits

Automated checks and keyboard testing cannot reproduce every assistive technology or individual access need. Formal conformance also requires ongoing manual testing and feedback from disabled users. Third-party websites linked from this resource have their own accessibility arrangements.

Tell us about a problem

If something is difficult to use, email saggartcitywesttogether@gmail.com. Please tell us which page you were using, what went wrong and, if you are comfortable doing so, the browser or assistive technology involved.
